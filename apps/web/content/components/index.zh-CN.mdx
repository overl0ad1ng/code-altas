---
title: 介绍
---

借助 Code Atlas 对 MDX 的支持，你可以创建自己的自定义组件，并直接在 MDX 文件中使用它们。Code Atlas 对此几乎没有限制。

此外，我们还提供了丰富的内置组件供你使用：

<Cards cols="2">
  <Card title="Cards / Card">

    使用响应式卡片网格组织相关内容，每张卡片可以包含标题、可选图标和富文本内容。

    [查看文档](/docs/components/cards)

  </Card>
  <Card title="Changelogs / Changelog">

    展示包含日期、标题、标签和 Markdown 正文的更新日志，支持按日期排序或保留编写顺序。

  </Card>
  <Card title="CodeBlock">

    将代码围栏渲染为带语法高亮的示例，支持文件名、行号、指定行高亮和复制按钮。

    [查看文档](/docs/writting/code-blocks)

  </Card>
  <Card title="CodeDiff">

    对比代码修改前后的内容，展示新增、删除的行及其原始行号。

    [查看文档](/docs/components/code-diff)

  </Card>
  <Card title="CodeGroup">

    将相关代码示例放在标签页中，方便读者切换语言、文件或不同实现。

    [查看文档](/docs/components/code-groups)

  </Card>
  <Card title="FAQ / Question">

    使用可展开的问答组织常见问题，并可指定一个默认展开的问题。

    [查看文档](/docs/components/faq)

  </Card>
  <Card title="FileTree">

    使用可展开的目录、文件图标和嵌套路径，说明项目的文件结构。

    [查看文档](/docs/components/file-tree)

  </Card>
  <Card title="Hint / HintTitle / HintContent">

    突出展示说明、提示和警告，支持组合标题与富文本内容，也可以设置折叠行为。

    [查看文档](/docs/components/hint)

  </Card>
  <Card title="Image">

    展示图片与图注，支持点击放大、Ctrl + 滚轮缩放和拖动查看细节。普通 Markdown 图片也会自动获得放大预览。

    [查看文档](/docs/components/image)

  </Card>
  <Card title="MermaidView">

    根据 Mermaid 源码渲染流程图、时序图等图表，Mermaid 代码围栏也会使用此组件展示。

    [查看文档](/docs/writting/mermaid)

  </Card>
  <Card title="PackageInstall">

    展示 npm、pnpm、Yarn 和 Bun 的安装命令，支持切换包管理器并复制命令。

    [查看文档](/docs/components/package-install)

  </Card>
  <Card title="Preview">

    同时展示可交互的组件示例和编写时的 MDX 源码，需要开启 MDX 组件预览实验选项。

    [查看文档](/docs/components/preview)

  </Card>
  <Card title="Props / Prop">

    通过属性名、类型、默认值和说明四列展示组件 API，每个 `Prop` 定义 `Props` 表格中的一行。

  </Card>
  <Card title="Status">

    标记组件的成熟度与版本节点，说明何时引入、弃用或停止支持。

    [查看文档](/docs/components/status)

  </Card>
  <Card title="Steps / Step">

    将教程与配置过程拆成步骤，为每个阶段提供标签、图标和详细内容。

    [查看文档](/docs/components/steps)

  </Card>
  <Card title="Surface">

    为内容提供统一的边框和背景，并可在顶部添加名称与简短说明。

  </Card>
  <Card title="Tabs / Tab">

    将不同平台、操作方式或示例放入具名标签页，支持为标签配置图标。

    [查看文档](/docs/components/tabs)

  </Card>
  <Card title="Tags">

    使用配置的颜色展示标签。文档 frontmatter 会自动渲染标签；自定义使用时可在 React 中导入 `Tags`，或自行注册到 MDX。

    [查看标签配置](/docs/writting/frontmatter)

  </Card>
  <Card title="Video">

    播放本地视频和远程 MP4，提供自定义的播放、进度、音量、倍速与全屏控件。

    [查看文档](/docs/components/video)

  </Card>
</Cards>

你也可以[创建并注册自己的组件](/docs/components/customization)。页面与布局组件的用法参见[布局与页面](/docs/layout-and-page)。
