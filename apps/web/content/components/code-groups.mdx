---
title: Code Groups
description: CodeGroup displays code blocks in tabs with language icons.
---

<Status since="0.1.3" />

<CodeGroup>
    ```tsx title="src/main.tsx"
    // code here
    ```
    ```html title="src/index/html"
    <!-- Code here -->
    ```
</CodeGroup>

Tab labels use the code block's `title`, falling back to its language. Icons are selected automatically from the language, such as TypeScript for `tsx` and HTML5 for `html`.

---

````mdx title="Usage"
<CodeGroup>
  ```tsx title="src/main.tsx"
  // code here
  ```
  ```html title="src/index.html"
  <!-- Code here -->
  ```
</CodeGroup>
````

  <Prop property="className" type="string" defaultValue="-" description="Additional classes for the group." />
