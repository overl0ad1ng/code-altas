```mdx title="Usage"
  </Question>

    Yes. Add Code Altas to your Next.js project.
  </Question>
  <Question title="Can I open several answers at once?">
    Opening another question automatically closes the previous answer.
  </Question>
</FAQ>
```

`FAQ` and `Question` are available automatically in MDX. In a React Server Component, import them from `@code-altas/ui`:

```tsx title="React import"
import { FAQ, Question } from "@code-altas/ui"
```

## Behavior

- Place `Question` components directly inside `FAQ`. React fragments are supported; arbitrary wrappers are not. Rendering `Question` independently throws an error.
- Set `defaultOpen` on at most one question per FAQ. Multiple defaults throw an error instead of silently choosing an answer.
- Without `defaultOpen`, all answers start collapsed. This prop only sets the initial state.
- Opening a question closes the previously open answer. Clicking an open question closes it, so all answers can be collapsed.
- Separate FAQ groups manage their state independently.
- Use **Tab** and **Shift + Tab** to focus question buttons, then **Enter** or **Space** to expand or collapse an answer.

## Answer content and icons

Answers accept Markdown and MDX, including lists, links, code blocks, and other components. Leave blank lines around Markdown inside `Question` to ensure it is parsed correctly.

`icon` is optional and uses the same icon names as other components, such as `lucide:rocket` or `simple:github`. Questions without an icon retain the same layout and interaction.
