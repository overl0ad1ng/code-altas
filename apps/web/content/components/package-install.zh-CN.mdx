## 用法

传入一个包名，即可为全部四种包管理器生成安装命令。每个标签页都会显示对应管理器的图标以及可复制的命令。

<Preview>
  <PackageInstall package="@code-altas/ui@beta" />
</Preview>


| 包管理器 | 命令 |
| --- | --- |
| npm | `npm install @code-altas/ui@beta` |
| pnpm | `pnpm install @code-altas/ui@beta` |
| yarn | `yarn add @code-altas/ui@beta` |
| bun | `bun add @code-altas/ui@beta` |

包的 scope、版本和分发标签都会被保留。你也可以传入多个以空格分隔的包名。

## 默认包管理器

默认选中的第一个标签页是 `npm`。可以使用 `defaultManager` 指定以其他包管理器作为初始选项。读者仍然可以在全部四个标签页之间切换。

<Preview>

<PackageInstall package="@code-altas/ui@beta" defaultManager="pnpm" />

</Preview>

```mdx title="Default Manager"
<PackageInstall package="@code-altas/ui@beta" defaultManager="pnpm" />
```
