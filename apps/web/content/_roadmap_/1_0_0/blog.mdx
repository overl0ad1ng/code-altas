Let projects share tutorials, announcements, and longer articles within the same Code Altas site.

## Goals

- Write blog posts in Markdown and MDX, reusing existing components for code examples and rich media.
- Provide a blog index with publication dates, summaries, and optional cover images.
- Present individual posts with author information, dates, tags, and a readable article layout.
- Support draft posts and predictable ordering without exposing unpublished content in the blog index.
- Generate article metadata and stable URLs for sharing and discovery.
- Integrate the blog with shared navigation, site themes, and responsive layouts.
