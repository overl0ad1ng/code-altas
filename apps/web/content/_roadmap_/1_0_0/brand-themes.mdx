Let projects express their own visual identity across the entire Code Altas site.

## Goals

- Customize colors, typography, spacing, and layout as a coherent theme.
- Carry the same visual identity through documentation, changelog, roadmap, and built-in content components.
- Support coordinated light and dark appearances.
- Offer ready-to-use themes that demonstrate distinct visual identities.
