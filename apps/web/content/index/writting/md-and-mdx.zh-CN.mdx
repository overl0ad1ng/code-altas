---
title: MD 与 MDX
---

CodeAltas 支持使用 Markdown（`.md`）和 MDX（`.mdx`）编写文档。

Markdown 提供了一种简单、易读的方式来创建结构化内容，而 MDX 在 Markdown 的基础上增加了组件能力，使文档能够包含交互式元素。本质上，MDX 是 Markdown 与 JSX 的结合。

## 什么是 Markdown？

Markdown（通常缩写为 MD）是一种轻量级标记语言。

它使用简单的符号来表示文本结构——例如标题、列表、链接和代码块——让作者能够专注于内容本身，而无需编写原始 HTML。

一个简单的 Markdown 文件：

```md
# Hello Code Altas

This is a paragraph.

- Item A
- Item B

1. List A
2. List B

... other
```

Markdown 的主要特点：

- 语法简单
- 纯文本文件格式
- 易于进行版本控制
- 适合编写文档、README、博客文章等

## 什么是 MDX？

MDX 代表 `Markdown + JSX`。它在 Markdown 的基础上扩展了 JSX 能力，允许在 Markdown 文件中直接使用 React 组件。

标准 Markdown 只能描述内容：

```md
# Installation

Install CodeAltas with npm.
```

而 MDX 则允许嵌入组件：

```mdx
# Installation

<Steps>
  <Step label="安装">将 Code Atlas 添加到项目中。</Step>
</Steps>
```

`Steps` 和 `Step` 是已经注册的内置 JSX 组件。

## Markdown 与 MDX 的区别

尽管 MDX 融合了 Markdown，但两者并不完全相同。

| 特性 | Markdown | MDX |
|---|---|---|
| 标题 | ✅ 支持 | ✅ 支持 |
| 列表 | ✅ 支持 | ✅ 支持 |
| 引用块 | ✅ 支持 | ✅ 支持 |
| 代码块 | ✅ 支持 | ✅ 支持 |
| 图片 | ✅ 支持 | ✅ 支持 |
| 链接 | ✅ 支持 | ✅ 支持 |
| HTML 元素 | ❌ 未启用原始 HTML | ✅ 使用 JSX |
| JSX 组件 | ❌ 不支持 | ✅ 支持 |
| React 组件 | ❌ 不支持 | ✅ 支持 |
| 导入 / 导出 | ❌ 不支持 | ❌ Code Atlas 中已禁用 |
| JavaScript 表达式 | ❌ 不支持 | ✅ 支持 |
| 视频 | ❌ 不支持 | ✅ 支持 |
| Tabs | ❌ 不支持 | ✅ 支持 |
| Steps | ❌ 不支持 | ✅ 支持 |
| FileTree | ❌ 不支持 | ✅ 支持 |

## Code Atlas 的渲染规则

上表描述的是 Code Atlas 实际渲染的内容。服务端渲染器禁用了 MDX 中的 `import` 和 `export`。需要使用自定义 React 组件时，应在 Next.js 页面中导入，再通过 `DocsPage` 的 `components` 属性注册：

```tsx title="app/docs/[[...slug]]/page.tsx"
import { DocsPage, type DocsPageProps } from "@code-altas/ui"
import { InstallCommand } from "../../../components/install-command"

export const dynamic = "force-dynamic"

export default function Page({ params }: DocsPageProps) {
  return <DocsPage params={params} components={{ InstallCommand }} />
}
```

示例假设项目已有 `components/install-command.tsx`，并导出 `InstallCommand`。注册后即可在 `.mdx` 文章中写 `<InstallCommand />`，无需在文章内导入。交互组件应在自己的模块中声明 `"use client"`，路由页面保持为 Server Component。

Markdown 渲染通过 GitHub Flavored Markdown 支持表格、任务列表和删除线。当前渲染器没有启用 `.md` 中的原始 HTML；需要 HTML 类元素时，请在 `.mdx` 中使用 JSX。MDX 支持 `{1 + 1}` 这样的表达式，因此应使用项目自己维护的文档源文件。

正文使用 `##`、`###` 编写章节，页面已将 frontmatter 标题渲染为主标题。图片放进 `public`，使用 `![截图](/images/screenshot.png)` 引用。`[快速开始](/docs/quickstart)` 指向已配置的文档，路径规则见 [文件系统](/docs/concepts/filesystem)，代码示例写法见 [代码块](/docs/writting/code-blocks)。
