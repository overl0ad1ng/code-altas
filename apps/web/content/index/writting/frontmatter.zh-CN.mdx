---
title: Frontmatter
---

你可以在 MD 或 MDX 文件中包含 frontmatter：

```md
---
title: Frontmatter
description: XXX
---
```

不过，并非放入 frontmatter 的任何内容都会被渲染。Code Altas 仅支持以下三个数据字段，且它们全部都是可选的：

## Title

`title` 会作为主标题渲染在页面的最顶部。它是可选的；如果未指定 `title`，则会改用 `codealtas.config` 中定义的 `name`。

## description

`description` 用于提供摘要。它会以更小、更浅的字体渲染在标题下方。

## tags

`tags` 字段接受一个值数组。你必须先在 `codealtas.config` 中定义标签数据：

```ts title="codealtas.config.ts"
import { defineConfig } from "@code-altas/ui";

export default defineConfig({
  docs: {
    tags: {
      "Beta": "#1447E6"
    }
  }
});
```

```md
---
title: Frontmatter
description: XXX
tags:
  - Beta
---
```

颜色 `#1447E6` 会以 100% 不透明度应用于文本（`Beta`），并以 20% 不透明度应用于边框。标签会渲染在描述下方。
