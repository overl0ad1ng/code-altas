---
title: Frontmatter
---

你可以在 MD 或 MDX 文件中包含 frontmatter：

```md
---
title: Frontmatter
description: XXX
---
```

不过，并非放入 frontmatter 的任何内容都会被渲染。Code Altas 仅支持以下三个数据字段，且它们全部都是可选的：

## Title

`title` 会作为主标题渲染在页面的最顶部。它是可选的；如果未指定 `title`，则会改用 `codealtas.config` 中定义的 `name`。

## description

`description` 用于提供摘要。它会以更小、更浅的字体渲染在标题下方。

## tags

`tags` 字段接受字符串数组。在 `codealtas.config.ts` 中定义标签颜色；文章标签没有配置非空颜色时不会显示：

```ts title="codealtas.config.ts"
import { defineConfig } from "@code-altas/ui/config";

export default defineConfig({
  title: "My Documentation",
  description: "Guides for my project",
  logo: "/logo.svg",
  docs: {
    tags: {
      "Beta": "#1447E6"
    }
  }
});
```

```md
---
title: Frontmatter
description: XXX
tags:
  - Beta
---
```

颜色 `#1447E6` 会以 100% 不透明度应用于文本（`Beta`），并以 20% 不透明度应用于边框。标签会渲染在描述下方。

Frontmatter 不会改变文档的 URL。`draft` 和 `disabled` 应配置在 `docs.categories` 的导航条目中，而不是 frontmatter 中。行为说明见 [导航配置](/docs/concepts/navigation)，浏览器标题与描述的接入方式见 [页面元数据](/docs/concepts/metadata)。
