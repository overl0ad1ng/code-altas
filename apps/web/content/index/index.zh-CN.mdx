## 什么是 Code Atlas？

Code Atlas 是一个基于 Next.js 的文档框架，适合编写项目指南、组件文档和 API 参考。

你可以从一个 Markdown 文件开始，逐步添加导航分类、代码示例和交互组件，让文档随着项目一起成长。

## 为什么选择 Code Atlas？

Code Atlas 提供开箱即用的现代界面，也支持自定义组件外观，或替换为你自己的组件。

- 免费且开源
- 现代界面
- 简单的配置
- 灵活的自定义能力
- 支持搜索引擎优化
- 支持自定义 MDX 组件

## 多语言文档

通过页面右上角的语言下拉框，可以切换同一篇文章的语言。没有中文翻译的文章会显示默认语言版本，并给出提示。
