---
title: 快速开始
description: 从安装到第一篇文章，搭建一个可以运行的 Code Atlas 文档站点。
---

本教程使用 Next.js App Router，将文档挂载在 `/docs`。已有 Next.js 项目可以从安装依赖开始，保留原有首页和业务路由。

## 1. 准备项目

使用 Node.js 22.12 或以上版本。项目需要 Next.js 16.3.6+（16.x）以及 React / React DOM 19.2.8+（19.x）。

没有项目时，创建一个启用 TypeScript 和 App Router 的 Next.js 项目：

```bash
pnpm create next-app my-docs
cd my-docs
```

安装 Code Atlas：

```bash
pnpm add @code-altas/ui@beta
```

包已包含 JavaScript、类型定义和编译后的 CSS，使用内置界面不需要额外安装 Tailwind。下面以 `app/` 为例；如果项目使用 `src/app/`，将路由文件放到 `src/app/`，其余文件位置保持不变。

## 2. 配置站点和第一篇文章

在应用的 `package.json` 旁创建配置文件：

```ts title="codealtas.config.ts"
import { defineConfig } from "@code-altas/ui/config"

export default defineConfig({
  title: "My Documentation",
  description: "Guides for my project",
  logo: "/logo.svg",
  docs: {
    categories: [
      {
        name: "Guides",
        icon: "lucide:book-open",
        slug: "index",
        docs: [{ name: "Introduction", slug: "index" }],
      },
    ],
  },
})
```

将你的 Logo 保存为 `public/logo.svg`。然后创建正文文件：

```md title="content/index/index.mdx"
---
title: 欢迎使用
description: 这是我的第一篇文档。
---

## 开始阅读

使用 Markdown 编写正文，使用 MDX 添加组件。
```

此处两个 `index` 保留在文件路径中，从公开 URL 中省略，因此文章的地址是 `/docs`。以后添加文章时，需要同时创建内容文件并注册导航条目，详见 [文件系统](/docs/concepts/filesystem)。

## 3. 配置 Next.js

将这些设置合并到现有配置，不要覆盖项目其他选项：

```ts title="next.config.ts"
import type { NextConfig } from "next"

const nextConfig: NextConfig = {
  serverExternalPackages: ["c12", "jiti"],
}

export default nextConfig
```

## 4. 添加根布局和文档路由

根布局提供 `html`、`body` 和全局样式。已有根布局时，合并样式导入与 `suppressHydrationWarning`，保留自己的 provider 和其他设置：

```tsx title="app/layout.tsx"
import "@code-altas/ui/styles.css"

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="zh-CN" suppressHydrationWarning>
      <body>{children}</body>
    </html>
  )
}
```

`DocsLayout` 会加载站点配置并提供文档导航、主题、header 和 footer：

```tsx title="app/docs/layout.tsx"
import { DocsLayout } from "@code-altas/ui"

export default function Layout({ children }: { children: React.ReactNode }) {
  return <DocsLayout>{children}</DocsLayout>
}
```

可选 catch-all 路由同时处理 `/docs` 和它下面的文章地址：

```tsx title="app/docs/[[...slug]]/page.tsx"
import { DocsPage, type DocsPageProps } from "@code-altas/ui"

export const runtime = "nodejs"
export const dynamic = "force-dynamic"

export default function Page({ params }: DocsPageProps) {
  return <DocsPage params={params} />
}
```

页面和布局保持为 Server Components，不添加 `"use client"`。`params` 是 Promise，由 `DocsPage` 负责读取。

## 5. 启动并检查

```bash
pnpm dev
```

访问 `http://localhost:3000/docs`，应看到「欢迎使用」的标题、正文和左侧导航。首页 `/` 仍由你的 Next.js 首页负责。

如果出现 404，检查配置、正文文件和路由是否都已创建，以及命令是否在应用根目录运行。不要同时保留 `app/docs/page.tsx` 与上述可选 catch-all 路由，它们会争用 `/docs`。
