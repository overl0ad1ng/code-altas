---
title: 布局与页面
---

与其他站点生成器不同，Code Altas 将主要关注点放在文档相关内容上。虽然布局可以完全自定义，但我们仍提供了一组开箱即用的组件，例如 `Header` 和 `Footer`，你可以通过 `codealtas.config.ts` 文件对它们进行配置。

## Docs

通常，你只需要以下几个布局与页面文件：

<FileTree
  files={[
    "src/app/docs/[[...slug]]/page.tsx",
    "src/app/docs/layout.tsx",
    "src/app/layout.tsx",
    "codealtas.config.ts",
  ]}
/>

### DocsLayout

如果你只需要维护 Docs 页面，可以直接这样配置：

```tsx title="src/app/docs/layout.tsx"
import { DocsLayout } from "@code-altas/ui"

export default function Layout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return <DocsLayout>{children}</DocsLayout>
}
```

### DocsPage

接下来，在 `page.tsx` 中配置 `DocsPage`：

```tsx title="src/app/docs/[[...slug]]/page.tsx"
import { DocsPage, type DocsPageProps } from "@code-altas/ui"

export const dynamic = "force-dynamic"

export default function Page({ params }: DocsPageProps) {
  return <DocsPage params={params} />
}
```

### codealtas.config

最后，在 `codealtas.config` 中配置与文档相关的设置：

```ts title="codealtas.config.ts"
import { defineConfig } from "@code-altas/ui/config"

export default defineConfig({
  title: "My Documentation",
  description: "Guides for my project",
  logo: "/logo.svg",

  docs: {
    categories: [
      {
        name: "Getting Started",
        icon: "lucide:lamp",
        slug: "index",
        docs: [
          {
            name: "Getting Started",
            docs: [
              {
                name: "Introduction",
                slug: "index",
              },
              {
                name: "Quick Start",
                slug: "quickstart",
              },
            ],
          },
        ],
      },
    ],
  },
})
```

## 注意事项

`docs` 目录会生成 `/docs` URL 前缀，`(site)` 这样的路由分组不会生成 URL 前缀。内置导航和文档链接指向 `/docs`，使用它们时请保留这个挂载路径。根布局 `app/layout.tsx` 应包含 `html` 和 `body`，完整示例见 [快速开始](/docs/quickstart)。

`DocsLayout` 负责加载配置、提供主题，并渲染 header、文档导航和 footer；`DocsPage` 负责读取和渲染正文。首页或变更日志可以在各自的布局中使用 `DefaultLayout`。不要在 `DocsLayout` 外再包一层 `DefaultLayout`，否则会出现重复的 header 和 footer。

1. 将 `content/` 目录放置在应用根目录下，与 `package.json` 和 `codealtas.config.ts` 保持同级。
2. 父级分组的 `slug` 会参与文件路径和 URL 的生成。`index` 仍会保留在文件路径中，但不会出现在 URL 中。
3. `index` 页面是可选的；只有在配置中声明的叶子文档才可以被访问和读取。
4. 请使用 Node.js Runtime，并确保部署时包含你的文档内容以及配置文件。
