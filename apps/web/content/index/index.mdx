Code Atlas is an open-source documentation system built on Next.js and React, designed for creating product guides, component documentation, and API references. You can start with a single Markdown file and gradually add navigation categories, code examples, and interactive components, allowing your documentation to evolve alongside your project.

## Why Choose Code Atlas?

We provide a modern, ready-to-use UI while offering powerful customization and extensibility. You can customize the appearance of any component or even completely replace them with your own custom components.

Compared to other common documentation systems, Code Atlas offers:

- Free and open-source
- Modern UI
- Simple configuration
- High customizability
- SEO-friendly
- Custom component support
