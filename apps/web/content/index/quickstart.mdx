---
title: Quick Start
description: Build a documentation site based on Code Altas in just a few minutes
---

> The first release is `0.1.0-beta`. Install the `beta` tag and pin the version for production deployments.

The package includes compiled JavaScript, types, and CSS. Importing `@code-altas/ui` loads its global styles; Tailwind is optional for your own UI. Keep pages and layouts as Server Components.

Add the configuration loader dependencies to `next.config.ts`:

```ts
import type { NextConfig } from "next"

export default {
  serverExternalPackages: ["c12", "jiti"],
} satisfies NextConfig
```

Deploy with a Node.js runtime and include `content/` and `codealtas.config.ts`. Use the App Router with Next.js 16.3.6+ (16.x) and React / React DOM 19.2.8+ (19.x).

    ## Prerequisites
    
    First, ensure you have the following tools installed:
    
    - Node.js: `^22.12.0, ^24.0.0, or >= 26.0.0`
    - pnpm: `11.18.0`
    
    ### 1. Create a Next.js project
    
    ```bash
    npx create-next-app@latest
    ```
    
    Follow the CLI prompts to complete the installation.
    
    ### 2. Install @code-altas/ui
    
    Install the `@code-altas/ui` package in the root directory of your project:
    
    ```bash
    pnpm add @code-altas/ui@beta
    ```
    
    ### 3. Configure codealtas.config.ts
    
    ```ts title="codealtas.config.ts"
    import { defineConfig } from "@code-altas/ui/config";
    
    export default defineConfig({
      title: "Code Altas",
      description: "This is a demo documentation site powered by Code Altas.",
      logo: "/logo.png",
      
      // other configurations
    });
    ```
    
    ### 4. Configure layout and page
    
    This step differs significantly from other similar site generators; Code Altas does not force specific content structures on your layouts and pages, allowing you to write exactly the components you want. Of course, you can also directly use the components we provide. 
    
    Examples include `DefaultLayout`, `DocsLayout`, `DocsPage`, etc. See details: [Components](/docs/components)
