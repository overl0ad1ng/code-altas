    <Changelog
        date="2026/10/20"
        title="Code Altas v0.4.0 — Roadmap Boards"
        tags={["Feature Milestone"]}
    >
        Turn a folder of MDX files into versioned planning boards with grouped columns, status badges, and rich item details.

        - Added `content/_roadmap_` discovery. Each version directory such as `1_0_0/` becomes a `v1.0.0` board, versions sort newest first, and boards are read when the route renders instead of being registered in `codealtas.config.ts`.
        - Added `roadmap.toml` for the board title, goal, columns (`groups`), and statuses, each with an ID, title, optional color and icon. IDs, colors, and item references are validated while loading.
        - Added MDX items: one file per card with YAML frontmatter for `title`, `description`, `group`, `status`, `order`, `release`, `priority`, `due`, `assignees`, and free-form `properties`. The document body is regular MDX.
        - Added `RoadmapPage` with a version selector, grouped columns and item counts, status badges, body previews, and participant avatars. Selecting a card opens the full MDX body beside a details panel.
        - Added `DefaultLayout` `contentMode="fill"` support so the board fills the viewport and its columns scroll independently.
        - Added output tracing for `/roadmap` in `next.config.ts` so local board content ships with the deployment.

        The board adds nothing to `docs.categories`, navigation, or search results, and it is intentionally not localized: one board serves every language. Render `RoadmapPage` from a route you own.

        Follow the [Roadmap guide](/docs/roadmap) to create a board, configure columns and statuses, and write items.

        [View the implementation commit](https://github.com/overl0ad1ng/code-altas/commit/de28342b39b5fab061b446c53b77a7ac0716e48b).
    </Changelog>
    <Changelog
        date="2026/10/4"
        title="Code Altas v0.3.3 — Mobile Navigation"
        tags={["Version Released"]}
    >
        Browse documentation on smaller screens with responsive navigation and dedicated menus.

        - Added a mobile header menu with site navigation, search, GitHub stars, theme controls, and language selection. The header keeps the logo and menu on the left and a search shortcut on the right.
        - Added a separate mobile documentation drawer with article title filtering, nested navigation, and full-width document content. Category changes keep the drawer open; selecting an article closes it.
        - Added category Select controls with icons and titles on mobile and on desktop when five or more categories contain published documents. Smaller desktop category lists retain the existing icon navigation.
        - Improved keyboard interactions, focus restoration, and the transition from navigation drawers to full-text search.
        - Stacked footer information vertically on mobile while retaining the desktop horizontal layout, and prevented fixed footer widths from overflowing documentation pages.
    </Changelog>
    <Changelog
        date="2026/10/3"
        title="Code Altas v0.3.0 — Documentation Search"
        tags={["Feature Milestone"]}
    >
        Find documentation by title, heading, body text, or code with locale-aware full-text search.

        - Added `docs.search` configuration and a search dialog with `Ctrl+K` / `Cmd+K` shortcuts, keyboard navigation, highlighted snippets, and links to matching headings.
        - Added `createDocsSearchHandler()` for the search API and `buildDocsSearchIndex()` for production index generation.
        - Added separate indexes for each language, excluding draft, disabled, and translation-fallback documents.
        - Added development index refresh, production index caching, and query validation. Production deployments must generate and include search indexes.

        Follow the [search setup guide](/docs/concepts/search) to configure the API and build step. This milestone covers header full-text search; sidebar title filtering was added afterward.

        [View the implementation commit](https://github.com/overl0ad1ng/code-altas/commit/ee0a53a661555734176b79f8d8647d7b665f2fb2).
    </Changelog>
    <Changelog
        date="2026/10/3"
        title="Code Altas v0.2.0 — Internationalization"
        tags={["Feature Milestone"]}
    >
        Publish documentation in multiple languages while sharing the same navigation structure and document slugs.

        - Added `docs.i18n` configuration for the default language, supported locales, and interface message overrides.
        - Added language-specific Markdown and MDX files, translated category and article names, and default-language content fallback with a reader notice.
        - Added a header language selector that preserves the current document, query string, and hash.
        - Added localized navigation, pagination, and internal documentation links, plus language-aware article attributes and canonical metadata.
        - Added English and Simplified Chinese documentation and interface messages.

        Follow the [internationalization guide](/docs/concepts/i18n) to configure locales and translation files. Default-language documents retain their existing URLs; other languages use a prefix inside `/docs`.

        [View the implementation commit](https://github.com/overl0ad1ng/code-altas/commit/ffeea03359923c2e07f06b707d9fac856f99f271).
    </Changelog>
